## 1. ภาพรวม

เกมเว็บแนว horde-survivor ภาพพิกเซลมุมบนแบบ Pokémon Game Boy ผู้เล่นแค่เดิน สกิลยิงเอง ฝ่าฝูงมอนผ่าน 8 Chapter ไปปราบ Umbra เล่นคนเดียวหรือ co-op 2–4 คน แข่งกันบน leaderboard รายฤดูกาล เล่นฟรีบนเว็บทั้งคอมและมือถือ ภาษาไทยเป็นหลัก + อังกฤษ งบค่าบริการ 0 บาท

**Design pillars** (ทุกการตัดสินใจเช็กกับข้อเหล่านี้)
1. เล่นง่าย ไม่ต้องคิดเยอะ แค่เดิน สกิลตีเอง
2. ตีมอนทีละเยอะๆ ฝูงมอนมารุม
3. ดาเมจสะใจ สกิลอลังการ
4. ภาพเรียบง่าย มุมบนแบบ Pokémon Game Boy
5. ระบบพัฒนาสกิลเป็นจุดขาย
6. ผ่านทีละด่าน ตายแล้วเริ่มใหม่ แต่สะสมของถาวรและคะแนน
7. เล่นกับเพื่อนและแข่งกัน

**ข้อจำกัดหลัก**: ฟรี ไม่หารายได้ (ไม่ปิดทาง donate ในอนาคต) · งบ 0 บาท · กราฟิกในเกมวาดเป็นแถวตัวอักษรในโค้ด ไม่ใช้ AI (ยกเว้นภาพพื้นหลังหน้าแรก) · Admin คนเดียว

## 2. โลกและเรื่องราว · #07

- **Lumora** (World แรก) ค้ำจุนด้วย **Heart of Lumora** **Umbra** เงาจากด้านมืดของหัวใจทุบมันแตก เศษคริสตัลทำให้มอนคลั่งเป็นฝูง คริสตัล EXP คือเศษหัวใจ ตื่นพลังคือฮีโร่รับพลังคริสตัลเต็มตัว Shadow Rival คือเศษเงาของ Umbra
- **โทน**: ผจญภัยสดใส มีมุกเล็กๆ story เบา: การ์ดเปิด Chapter + บอสพูด 2–3 บรรทัด กดข้ามได้ ชื่อเฉพาะภาษาอังกฤษ ข้อความเรื่องภาษาไทย (มีฉบับอังกฤษ)
- **ฮีโร่ 4 คน** (ทีมเดียวกัน บทพูดของตัวเอง 1 บรรทัดต่อ Chapter): Lyra (Mage), Bram (Knight), Kit (Ranger), Vex (Alchemist) — ดู §5
- **10 ดินแดน + Heart Crater** ราชาแต่ละองค์ถูกเศษคริสตัลครอบงำ มีนิสัยเป็นมุกประจำตัว:

## 3. โครงหนึ่งรอบ (Run) · #08, #22

- **8 Chapter × 1 Stage ≈ 20 นาที** Ch1 = Greenvale (สอนเล่น) · Ch2–7 เลือก 1 ใน 2 ดินแดนที่ยังไม่ได้ไป (เห็น 6 จาก 9 ต่อรอบ) · Ch8 = Heart Crater ความยาว Stage `min(150, 60+20·(n−1))` วิ
- **ความยากผูกกับเลข Chapter** ไม่ใช่ตัวดินแดน ดินแดนกำหนดชนิดมอน ลักษณะเด่น และธาตุที่ทน
- **ราชาต้องตายถึงจะผ่านด่าน**: หมดเวลาแล้วต่อเวลา ~45 วิ (ราชาโกรธ มอนทะลัก) ยังไม่ตาย = **Escape**: ราชาหนีพร้อมเศษคริสตัล ไม่ได้รางวัลราชา Umbra แข็งขึ้น (HP +15%/ตัว + ได้ท่าไม้ตายของราชาตัวนั้น) มีบทพูดบอก เลือกดินแดนใหม่ใน Chapter เดิมได้ 1 ครั้ง
- **อีเวนต์** (Ch2–7 เท่านั้น): Blood Moon (ไม่บอกล่วงหน้า), Guardian ใน Blood Moon ตามธาตุดินแดน, Shadow Rival, ด่านราชา 2 ตัว (Ch4–7, 10%)
- **ชนะ Umbra** → ได้อาวุธที่ยังไม่มีทันที (มีครบแล้วได้ 500 Gold) → เลือกเล่นต่อ **Endless** (รอบเดิม ของครบ คะแนนโหมดหลักบันทึกแล้ว) หรือจบ ตายใน Endless = จบรอบตามปกติ
- **หัวใจร้าว 1–3** (ระดับความยากที่ปลดล็อกหลังชนะ) อยู่ในรุ่นแรก ระดับ 4–10 เป็นอัปเดต
- **เซฟแล้วเล่นต่อ**: เซฟอัตโนมัติทุกต้นด่าน + Esc ออก กลับมาที่ต้นด่าน ใช้ได้ครั้งเดียว เก็บบน server + สำเนาในเครื่อง (hash กันก๊อปเซฟ) ใช้ได้ในโหมดหลักและ Endless แบบ solo · ไม่มีใน co-op และด่านประจำวัน · ตายแล้วเริ่มใหม่เสมอ · เวลาพักไม่นับในกันโกง · Season จบระหว่างพัก = ไม่ขึ้นอันดับ

## 4. ระบบสกิล v2 · #18, #23

- **ช่อง**: โจมตี 4 (Signature Skill ล็อก 1 + ทั่วไป 3) · พาสซีฟ 3 (Evolution สูงสุด 3 ครั้งต่อรอบ) · **Bench** เริ่ม 1 ช่อง +1 เมื่อผ่าน Ch2 และ Ch4
- **เลเวลอัป** เสนอ 3 ตัวเลือก ช่องโจมตีเต็มแล้วสกิลใหม่เข้า Bench ได้ สกิลใน Bench คงเลเวลแต่ไม่ถูกเสนออัป Signature Skill ถูกเสนอบ่อยกว่าเล็กน้อย ป้ายช่วย ("เข้าคอมโบกับ Frost", "นับเป็น Link")
- **สลับ Bench ↔ ช่องโจมตี** ตอนจบด่านเท่านั้น จ่าย Gold 20 × เลข Chapter (ครั้งที่ 2 ในด่านเดียวกัน ×2)
- **Evolution** 12 แบบเดิม (สกิลเต็ม + พาสซีฟคู่) เช่น Bolt + Haste = Arcane Barrage
- **Link → Awakening**: สกิลทั่วไป 12 ตัวแบ่ง 4 **Skill Line** (Lyra: Bolt/Chain/Hole · Bram: Orbit/Lance/Nova · Kit: Disc/Cyclone/Meteor · Vex: Toxic/Frost/Laser) ทุกฮีโร่หยิบได้ทุกสกิล แต่นับเป็น Link ได้เฉพาะสายตัวเอง เงื่อนไข: Signature Evo แล้ว + Link 2 ใน 3 เต็มเลเวล ติดในช่องโจมตี และเต็มมาแล้ว ≥1 ด่าน (ไม่มีเงื่อนไขเลเวลผู้เล่น) หน้ายืนยันเด้งตอนจบด่าน รับ = กิน Link 2 ตัว ร่างเปลี่ยน สกิลสาย 3 ตัวเข้ามาในตัวเลือก (เริ่ม Lv1 ไม่มี Evolution แต่แรงกว่า) ปฏิเสธ = หมดโอกาสในรอบนั้น
- **Combo** (อัตโนมัติ): Status 5 แบบ แข็ง 1.5 วิ (บอสแค่ช้า) · รวมกลุ่ม · ไหม้ 3 วิ · ช็อต 2 วิ · พิษ 4 วิ → คอมโบ 7 แบบ: Shatter (แข็ง+ตีแรง ×2.5), Firestorm (รวมกลุ่ม+ไฟ), Overload (ช็อต+ไฟ 150%), Superconduct (แข็ง+สายฟ้า ลบเกราะ 5 วิ), Toxic Burst (พิษ+ไฟ ×2), Grinder (รวมกลุ่ม+ตัวกวาด +50%), Catalyst (Bolt บนสถานะใดก็ได้ +50%) ติดซ้ำบนมอนตัวเดิมได้ทุก 1 วิ co-op: คอมโบเฉพาะของตัวเอง
- **แพ้ทาง-ชนะทาง**: ศัตรู 5 แบบ (เกราะ, ฝูงเร็ว, ยิงไกล, บอส, แตกตัว) แต่ละดินแดนมีลักษณะเด่นและมอนทนธาตุของตัวเอง (−50%) หน้าจบด่าน/เลือกเส้นทางบอกลักษณะเด่นและสกิลที่ได้เปรียบ
- **Skill Point** (รางวัลบอส): reroll 1 · banish 1 · อัปสกิล +1 ทันที 2 (แลก Gold ได้ 30 × Chapter ต่อแต้ม)
- **Ultimate**: เกจเติมตามเวลาเป็นหลัก (เต็ม 60 วิ การฆ่าช่วยได้ไม่เกิน 1 เท่า → เร็วสุด ~30 วิ) ดาเมจผูกกับ HP มอนของ Chapter (1.5 เท่า) ไม่ผ่านโบนัส Might/Power/คริ เพดานต่อบอส 8% (Umbra 5%)
- **เป้าความกดดัน** (ใช้จูน): Ch1–3 สบาย · Ch4–7 เสีย HP < 50% อย่างน้อย 1 ครั้งต่อด่าน ท่าอันตรายทุก 10–15 วิ · Ch8 build ไม่ดีแพ้ได้ · ห้ามมีช่วงปล่อยมือได้ > ~20 วิ โดยไม่เสียเลือด
- เอกสารภาพ: `docs/blueprint/skill-system.html`

## 6. ศัตรู บอส และมังกร · #09, #21

- **มอนต่อดินแดน** 3 บทบาท (ตัวรุม · ตัวเด่น · ตัวถึก) — ตารางเต็มใน #09 เช่น Gearspire: แมงมุมเหล็ก · ป้อมปืนยิงไกล · ทหารกลไกใส่เกราะ (ทนสายฟ้า) มอนแก้ทางเดิม (หมูป่า, ตาเวท, สไลม์แตกตัว, ตัวใส่เกราะ) โผล่ทุกดินแดนแบบเปลี่ยนสี Heart Crater = ร่างเงาของทุกดินแดน
- **ราชา**: 2 ช่วง (ท่าปกติ 2 · ต่ำกว่า 50% เพิ่มท่าไม้ตาย เตือน ~1.2 วิ) บทพูด 4 จังหวะ (โผล่/50%/ตาย/หนี) ทุกท่ามีเครื่องหมายเตือนก่อน ท่าของทั้ง 10 องค์อยู่ใน #21 (เช่น Golem King: PROTOCOL: PURGE เลเซอร์หมุน 360°)
- **Guardian** (บอสใน Blood Moon → สัตว์คู่ใจ): Inferno (ไฟ), Frost (น้ำแข็ง, พายุหิมะ: หยุดเดิน = แข็ง), Storm (สายฟ้า) หลังได้ตนแรก ตนที่เหลือเจอง่ายขึ้น (Blood Moon ในดินแดนธาตุที่ยังขาด ×2, มังกรโผล่ 60%)
- **Companion**: ใช้งาน 1 + เก็บ 2 เลเวล 1–5 ในรอบ (การ์ดในเลเวลอัป / Skill Point 2 / ปราบตนเดิมซ้ำ +2) Lv3 ปลดท่าที่ 2 · Lv5 ร่างโต ท่ามังกรทิ้ง Status และต่อคอมโบกับสกิลเจ้าของได้
- **มังกร 3 หัว**: ปราบครบ 3 ตน**ในรอบเดียว** → เลือกรวมร่างตอนจบด่าน เลเวลเริ่ม = เฉลี่ยของ 3 ตน (≥3) มี Tri-Breath เป้าให้เกิด ~2–5% ของรอบที่เล่นจบ
- **Umbra** 3 ช่วง: ร่างเงา (สกิลลอกเลียนฮีโร่) → ร่างราชา (ท่าไม้ตายของราชาที่หนี หรือของราชาที่ปราบแบบอ่อน) → ร่างหัวใจแตก (จอมืด แสงรอบตัว)
- **ด่านราชา 2 ตัว**: ตัวที่ 2 = ราชาของดินแดนที่ไม่ได้เลือก HP ตัวละ ×0.7 ได้รางวัลทั้งคู่

## 7. เศรษฐกิจ ของถาวร และ meta · #20, #09, #23, #15

- **Gold** ≈ 1,200 ต่อรอบเต็ม · ร้านถาวร (Power, Vigor, Agility, Greed, Wisdom, Second Wind) เต็มหมด ≈ 12,600 · **ร้านเปิดเฉพาะนอกรอบ** · ใช้ในรอบหักจาก Gold ของรอบก่อน
- **ใช้ Gold ในรอบ**: สลับ Bench 20 × Ch · **ใบเกิด** 75 × Ch (1 ครั้งต่อรอบ แยกจาก Second Wind, ปิดในด่านประจำวัน, co-op ใช้ลุกทันที) · แลก Skill Point 30 × Ch
- **รางวัลราชา (ได้เสมอ)**: Gold 50 × Ch + Skill Point 1 + หีบวงล้อ (อัปเกรดฟรี ×1/×2/×3 = 50/35/15%) + อาวุธประจำดินแดน 5% (ถ้ายังไม่มี) ราชาหนีไม่ได้อะไร
- **Weapon** (10 ชิ้น ดินแดนละ 1 + Judgement เริ่มต้น): เปลี่ยน**แค่รูปแบบ Ultimate** ไม่ให้ค่าพลัง ท่าไม้ตายทิ้ง Status (เช่น Glacier Lance → Absolute Winter แช่แข็งทั้งจอ) ได้กลางรอบเปลี่ยนใช้ตอนจบด่านถัดไป เลือก 1 ชิ้นก่อนเริ่มรอบ
- **Achievement ~30** (เนื้อเรื่อง, ฮีโร่, คอมโบ, มังกร, ท้าทาย) บางรายการให้ **Title** · **สมุดรวมมอน** (ฆ่าครั้งแรกปลดหน้า) · **สกิน** = ชุดสี (จาก Season/achievement) · ภารกิจรายวัน = อัปเดตภายหลัง
- **ของในรอบ vs ถาวร**: เริ่มรอบใหม่ สกิล/เลเวล/มังกร/Bench/Skill Point หายหมด · Gold, ร้าน, ฮีโร่, อาวุธ, ฉายา, achievement ติดตัว

## 8. คะแนน leaderboard และ Season · #15

## 9. Co-op · #16, #03, #12

- 2–4 คน **รหัสห้อง 5 ตัว** + ลิงก์ชวน เข้าได้เฉพาะห้องรอ (หลุดแล้วกลับได้) ห้อง = Cloudflare Durable Object ผ่าน PartyServer (WebSocket ผ่าน CGNAT) สำรอง: PeerJS + Cloudflare TURN
- **โฮสต์คำนวณโลก** ส่ง snapshot ~15 Hz (มอนอัด 11 ตัวอักษร ≤ 4 KB) เพื่อนคำนวณสกิลตัวเองแล้วส่งดาเมจรวมทุก 150 ms (โปรโตคอลเดิม)
- โหวตเส้นทาง 15 วิ (เสมอ = โฮสต์) · เลเวลอัป/หีบ ทั้งห้องรอ · หน้าจบด่าน จัดการของตัวเองพร้อมกัน (รอพร้อม หรือ 30 วิ)
- มอนเกิด +60% ต่อเพื่อน · HP ราชา/มังกร/Umbra ×(1 + 0.6 × จำนวนเพื่อน)
- ทุกคนได้ของครบของตัวเอง (EXP ทีม, Gold ตามจำนวนฆ่าของทีม, รางวัลราชา, มังกร)
- ล้ม → รอผ่านด่าน / ซื้อใบเกิด / **เพื่อนยืนข้าง 3 วิ ลุก HP 30%** (คนละครั้งต่อด่าน) ทุกคนล้ม = จบรอบ
- ใช้ Balance Config ของโฮสต์ · เช็กสวิตช์ co-op ตอนสร้าง/เข้าห้อง · Endless โหวตเล่นต่อ
- **รุ่นแรก**: โฮสต์หลุด = ห้องปิด ทุกคนได้ของที่เก็บไว้ · **อัปเดต**: ย้ายโฮสต์ (เพื่อนคนแรกเป็นโฮสต์ใหม่ เริ่มด่านใหม่จากเซฟต้นด่าน)
- โควตาฟรี ~6–12 ชม.เล่น 4 คนต่อวัน เกินแล้วขึ้น "co-op เต็มวันนี้" (รีเซ็ต 07:00 เวลาไทย)

## 13. Sim และโครงโค้ด · #11, #05

- `packages/sim` = โมดูลลึก: `createSim({seed, config, world, hero, weapon, meta})` → `step(inputFrame, commands)` / `view()` / `score()` / `hash()` ใช้ตัวเดียวกันในเกม ชุดทดสอบ และตัวตรวจ replay
- **เล่นซ้ำได้ผลเดิมตั้งแต่ตอนย้ายโค้ด**: 60 tick คงที่ · RNG seed ได้แยก stream (`fxRng` สำหรับภาพ) · `fmath` แทน `Math.sin/cos/atan2/hypot/pow/exp/log` · ESLint ห้าม `Math.random`/`Date.now`/`performance.now` ใน sim · บันทึก InputFrame + Command ตลอด · state hash ทุก 60 tick · `scoreOf` ที่เดียว
- **Balance Config** = zod schema (ค่าเริ่มต้น + ช่วงค่า + คำอธิบาย) ใช้เป็น type, ตัวตรวจ, ฟอร์ม Admin และตัวตรวจฝั่ง server แบ่งค่ากลาง + ค่าเฉพาะ World มีผลตอนเริ่มด่านถัดไป **Feature flags** แยก มีผลทันที
- เนื้อหาแยกตาม World: `packages/sim/content/<world>/` (ตอนนี้ `lumora`)
- **ลำดับการย้าย**: ย้ายโค้ดโดยเกมเล่นเหมือนเดิม + วางฐาน determinism → ชุดทดสอบ + replay ทองคำ → backend/Admin/co-op → ระบบใหม่
- กฎเดิม: ดาเมจใส่มอนผ่าน `hit()` เท่านั้น ดาเมจใส่ผู้เล่นผ่าน `hurtP()` เท่านั้น ตัวนับเดิม `combo` เปลี่ยนชื่อเป็น Kill Streak

| ความสมดุลของตัวเลขเริ่มต้น | ทุกค่าอยู่ใน Balance Config จูนจากสถิติตามเป้าความกดดัน (§4) |
| ความซับซ้อนของระบบสกิลขัด pillar ข้อ 1 | ตัดสินใจเฉพาะตอนเกมหยุด + ป้ายช่วย + สอนตอนเจอครั้งแรก |
| determinism ข้าม browser | `fmath` + ESLint + ทดสอบ hash ใน Chromium/Firefox/WebKit ทุก build |
