ระบบของเกมตอนนี้ทำงานอย่างไร

พิมพ์เขียวของไฟล์เดียว pixel-horde.html (1,758 บรรทัด, vanilla JS + Canvas 2D, ไม่ใช้ไลบรารีใดเลย) ณ วันที่ 2026-09-24 — สี่ภาพ: ส่วนประกอบในไฟล์, สถานะของเกม, วงจรที่ทำให้สนุกและอยากกลับมาเล่น, และการส่งข้อมูลตอนเล่น co-op

01

ส่วนประกอบทั้งหมดในไฟล์เดียว

architecture

ทุกอย่างอยู่ในไฟล์เดียว: ลูปหลัก เรียก update() ทุกเฟรม และ ส่วนจำลองโลกเกม เป็นศูนย์กลางที่ส่งต่อไปยังภาพ เสียง และหน้าจอเมนู ภาพ เสียง และข้อมูลเกมทั้งหมดถูกสร้างจากโค้ด จึงนำไปวางที่ไหนก็ได้ ยกเว้น กล่องสีแดง ซึ่งเป็นส่วนเดียวที่ผูกกับ Claude ถ้านำเกมไปโฮสต์ที่อื่น co-op ชื่อผู้เล่น และกระดานคะแนนจะหายไปเงียบๆ โดยไม่มี error ให้เห็น

02

สถานะของเกม: ตอนนี้ผู้เล่นอยู่หน้าไหน

state machine

ผู้เล่นอยู่ใน play เกือบตลอดเวลา เลเวลอัปกับหีบหยุดเกมทุกครั้ง แล้วกลับมาเล่นต่อทันทีที่เลือกเสร็จ และใน co-op ทั้งห้องจะรอคนที่กำลังเลือกอยู่ เพื่อให้ภาพอ่านง่าย จึงรวม clearing (ฉากจบด่าน 1.5 วิ) กับ clear ไว้ในกล่องเดียว ย้าย pause ไปเป็นหมายเหตุ และเขียนปุ่ม “กลับหน้าแรก” ไว้ในกล่องเกมโอเวอร์แทนการลากเส้น

03

ทำไมหนึ่งรอบถึงสนุก และทำไมถึงอยากกลับมาเล่น

loop

วงในหมุนทุกไม่กี่วินาที: ฆ่า → เก็บ XP → เลเวลอัป → เลือกอัปเกรด → ยิงแรงขึ้น → ฆ่าได้เร็วขึ้น ทุกการเลือกสะสมเข้า “พลังของผู้เล่น” ส่วน Director กับ HP ศัตรูที่โตขึ้นทุกด่านคอยดันกลับไม่ให้ง่ายเกินไป วงนอก (ทอง → ร้านค้าถาวร → รอบถัดไป) คือเหตุผลที่ทำให้อยากกลับมาเล่นอีก แม้รอบนี้จะแพ้ก็ตาม

04

ข้อมูล co-op วิ่งอย่างไรในตอนนี้

sequence

Host คิดทุกอย่าง แล้วประกาศสถานะผ่านห้องของ Claude ส่วน guest ยิงสกิลเองในเครื่องและส่งกลับแค่ดาเมจรวม ข้อความเส้นประทุกเส้นต้องวิ่งผ่านห้องของ Claude ซึ่งเป็นส่วนที่ต้องแทนด้วย Cloudflare Durable Object relay โดยรูปแบบ “host เป็นคนตัดสิน” ยังใช้ได้เหมือนเดิม

ET · THEMES

ศัตรู

  • แต่ละธีมมีมอน 3 แบบ + บอส 1 ตัว: King Slime (หญ้า), Sand King (ทะเลทราย), Bone King (ถ้ำ), Frost King (หิมะ)
  • Wild Boar (ด่าน 2+): ส่งสัญญาณก่อนพุ่งชน
  • Eye Caster (ด่าน 3+): ยิงจากระยะไกล

  • Split Slime (ด่าน 4+): ตายแล้วแตกเป็น 3 ตัว

RUN-ONLY REWARDS

อีเวนต์พิเศษ

  • Blood Moon (ด่าน 2+): โอกาส 10% และ +6% ทุกครั้งที่ไม่เกิด · ศัตรูเกิด ×2.3 · เหรียญ ×2 · ได้หีบโบนัส
  • Inferno Dragon (เฉพาะใน Blood Moon, ด่าน 3+): โอกาส 25% และ +15% ทุกครั้งที่ไม่เกิด · ท่าทุกท่ามีสัญญาณเตือน · รางวัลคือ มังกรไฟสัตว์เลี้ยง (สะสมเลเวลได้)
  • Shadow Rival (ด่านปกติ 2+): โอกาส 25% · ต้องล้มให้ได้ใน 35 วิ · รางวัลคือ Shadow Clone (35%) ไม่งั้นได้เศษ 1 ชิ้น ครบ 3 ชิ้นได้ Clone
