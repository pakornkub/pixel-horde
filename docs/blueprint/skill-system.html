ระบบสกิล: ของเดิม และระบบ v2

ส่วนแรกคือสกิล 12 แบบในเกมตอนนี้ (สูตรจาก pixel-horde.html) ส่วนที่สองคือระบบสกิล v2 ที่ตัดสินแล้วใน ticket ⑱ (2026-09-24) กติกาเต็มอยู่ในคำตอบของ ticket นั้น

1. สกิลในเกมตอนนี้

เลือกสกิล ลากเลเวล แล้วติ๊ก Evolution เพื่อดูค่าที่เปลี่ยนไป

เลเวล1 / 8

ดาเมจที่แสดงคือค่าพื้นฐาน ของจริงคูณด้วยโบนัสผู้เล่น: 1 + 0.2×Might + 0.08×Power (ร้าน) + 0.15 ถ้าเป็น Mage, สุ่ม ±12%, คริติคอลสูงสุด 50% ×(2 + 0.2×Keen Eye) และคูลดาวน์ลดได้สูงสุด 40% ตอนนี้ถือสกิลโจมตีได้ 6 ช่อง และเก็บพาสซีฟได้ครบทั้ง 6 แบบ

2. ระบบสกิล v2 (ตัดสินแล้ว)

กดสลับชั้นข้อมูล แล้วคลิกกล่องใดก็ได้เพื่อดูความสัมพันธ์ ชื่อสกิลประจำตัวและสกิลสายเป็นชื่อชั่วคราว รอ ⑲ ออกแบบตัวละคร

ช่องโจมตี 4สกิลประจำตัว (ล็อก) + สกิลทั่วไป 3
ช่องพาสซีฟ 3จำกัด Evolution ได้สูงสุด 3 ครั้ง
ช่องเก็บ 1 → 3เริ่ม 1 ช่อง +1 เมื่อผ่าน Ch2 และ Ch4 · สลับตอนจบด่าน จ่าย Gold
อัปสกิล→เลเวลเต็ม + พาสซีฟคู่→Evolution→สกิลประจำตัว Evo แล้ว + Link 2 ใน 3 เต็มและใช้มาแล้ว 1 ด่าน→ตื่นพลัง (Awakening)→ปลดล็อกสกิลสาย 3 ตัว

3. ทำไมแบบนี้ถึงสมดุล

  • ลดพลังดิบ แต่คงความอลังการ: ช่องโจมตีจาก 6 เหลือ 4 (สกิลยิงพร้อมกันลดลงราว 1/3) แล้วย้ายความสะใจไปที่คอมโบ
  • พาสซีฟ 3 ช่อง = Evolution สูงสุด 3 ครั้งต่อรอบ: เดิมเก็บพาสซีฟได้ครบ 6 แบบ จึง Evo ได้แทบทุกสกิล การเลือกพาสซีฟจึงเท่ากับเลือกว่าจะ Evo สกิลไหน
  • สกิลทั่วไปแบ่ง 4 สาย สายละ 3: ทุกตัวละครหยิบได้ทุกสกิล แต่นับเป็น Link ได้เฉพาะสายตัวเอง ต้องเลือกระหว่างเดินสายตัวเองเพื่อไปตื่นพลัง กับผสมสายเพื่อเอาคอมโบ
  • Link ใช้ 2 ใน 3: สกิลประจำตัว + Link 2 + ว่าง 1 ช่องไว้สำหรับคอมโบหรือแก้ทาง ต้องติดอยู่ในช่องโจมตี (ช่องเก็บไม่นับ) และเต็มเลเวลมาแล้วอย่างน้อย 1 ด่าน ไม่มีเงื่อนไขเลเวลผู้เล่น
  • ตื่นพลังเป็นการแลก: เสียสกิลเต็มเลเวล 2 ตัว ได้สกิลประจำตัวร่างใหม่ + สกิลสาย 3 ตัวที่เริ่มจาก Lv1 พลังจะตกก่อนแล้วค่อยสูงกว่าเดิม ปฏิเสธได้ แต่หมดโอกาสในรอบนั้น
  • คอมโบเกิดเองอัตโนมัติ: สกิลทิ้งสถานะไว้บนมอน (แข็ง, รวมกลุ่ม, ไหม้, ช็อต, พิษ) แล้วสกิลอีกธาตุมากระตุ้น คอมโบส่วนใหญ่ข้ามสาย Alchemist เป็นตัวละครสายคอมโบ
  • แพ้ทาง-ชนะทาง + ช่องเก็บ: จบด่านแล้วเกมบอกว่าด่านต่อไปเจออะไร สลับสกิลจากช่องเก็บด้วย Gold ถาวร
  • ทุกตัวเลขปรับได้ใน Balance Config: จำนวนช่อง, ตัวคูณคอมโบ, เลเวลขั้นต่ำของการตื่นพลัง และค่าสลับ

4. ยังต้องตัดสินใจ

  • ชื่อและรูปแบบสกิลประจำตัวและสกิลสาย (⑲ หลัง ⑦ story)
  • ตัวเลขจริงทั้งหมด (ราคาสลับ, ตัวคูณคอมโบ, พลังของสกิลสาย) จูนจากสถิติใน Admin ตามเป้าความกดดันใน ⑱
  • ราคาสลับสกิลและราคาช่องเก็บในร้าน (⑳)
