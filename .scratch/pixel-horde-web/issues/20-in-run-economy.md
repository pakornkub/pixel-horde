# Grilling: เศรษฐกิจในรอบ: Gold, รางวัลบอส, ใบเกิด

Type: grilling
Status: open
Blocked by: 18

## Question

เมื่อ **Gold ถาวร**ถูกใช้ในรอบด้วย (ผู้ใช้ยืนยันแล้ว) จะสมดุลกับร้านอัปเกรดถาวรยังไง? ต้องตัดสิน:
- ราคาสลับสกิลต่อครั้ง (ร่วมกับ #18)
- **ซื้อใบเกิดตอนตาย** ได้ 1 ครั้งต่อรอบ ราคาเท่าไร, ซ้อนกับ Second Wind ในร้านยังไง, ปิดในด่านท้าทายประจำวัน และทำงานยังไงใน co-op
- **รางวัลบอส**: สุ่มระหว่าง Gold / แต้มสกิล / หีบวงล้อเดิม ข้อแนะนำคือได้อะไรเสมอ แต่สุ่มขนาด (ผู้ใช้เคยเสนอให้มี "ไม่ได้อะไร" ต้องตัดสินให้จบ)
- Gold ในรอบถูกเก็บเข้ากระเป๋าเมื่อไหร่ (ตอนนี้เก็บตอนผ่านด่านหรือตอนตาย) และจะกันไม่ให้ใช้ Gold ในรอบจนร้านถาวรไม่มีความหมายได้ยังไง

เพิ่มจาก #07 (แก้ไข): รวมร่างมังกร 3 หัวต้องปราบครบ 3 ตนในรอบเดียว ไม่นับข้ามรอบ ต้องตั้งค่าโอกาสเจอมังกรตนที่ยังไม่ได้ให้สูงขึ้นหลังได้ตนแรก
