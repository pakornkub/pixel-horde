## Question

ต่อยอดร่างที่ผู้ใช้เห็นชอบทิศทางแล้ว (`docs/blueprint/skill-system.html` ส่วนที่ 2) ให้เป็นกติกาที่ครบ:

- **ช่อง**: โจมตี 4 (สกิลประจำตัวล็อก 1 + ทั่วไป 3), พาสซีฟ 3, ช่องเก็บ 3 จำนวนช่องต้องปรับได้ใน Balance Config
- **สลับสกิล** ระหว่างช่องเก็บกับช่องโจมตี ทำได้ตอนจบด่านเท่านั้น จ่ายด้วย **Gold ถาวร** (ผู้ใช้ยืนยันแล้ว) ต้องตั้งสูตรราคา และบอกว่าสกิลในช่องเก็บยังรักษาเลเวลไว้ไหม
- **Evolution เดิม 12 แบบ** คงไว้ (สกิลเต็ม + พาสซีฟคู่) สกิลประจำตัวก็ Evo กับพาสซีฟได้ เพราะมีพาสซีฟ 3 ช่อง จึง Evo ได้สูงสุด 3 ครั้งต่อรอบ
- **Link และตื่นพลัง (Awakening)**: สกิลประจำตัว Evo แล้ว + สกิลในสายของตัวละครเต็มเลเวล 2 ใน 3 ที่ติดอยู่ในช่องโจมตี (ช่องเก็บไม่นับ) + ถึงเลเวลผู้เล่นที่กำหนด (รอ #08) → มีหน้าจอเด้งให้เลือก รับแล้วกิน Link 2 ตัว ร่างสกิลเปลี่ยน ปลดล็อกสกิลสาย 3 ตัว ไม่รับแล้วหมดโอกาสในรอบนั้น ต้องมีข้อความยืนยัน
- **จัดสกิลทั่วไป 12 ตัวเข้า 4 สาย** (ร่าง: Mage = Bolt/Chain/Hole, Knight = Orbit/Lance/Nova, Ranger = Disc/Cyclone/Meteor, Alchemist = Toxic/Frost/Laser)
- **คอมโบ**: สถานะ 5 แบบ (แข็ง, รวมกลุ่ม, ไหม้, ช็อต, พิษ) + ปฏิกิริยา 6 แบบ (Shatter, Firestorm, Overload, Superconduct, Toxic Burst, Grinder) + Bolt เป็น Catalyst เกิดเองอัตโนมัติ มีตัวหนังสือบอกเมื่อติดคอมโบ ต้องตั้งตัวคูณ และระยะเวลาของแต่ละสถานะ
- **แพ้ทาง-ชนะทาง**: ศัตรู 5 แบบ (เกราะ, ฝูงเร็ว, ยิงไกล, บอส, แตกตัว) กับหน้าจบด่านที่บอกด่านต่อไปและแนะนำสกิลที่ได้เปรียบ
- **แต้มสกิล** (รางวัลจากบอส ผู้ใช้ยืนยันแล้ว) ใช้ทำอะไร เช่น อัปสกิลโดยไม่ต้องรอเลเวลอัป หรือรีโรลตัวเลือกตอนเลเวลอัป
- หน้าเลือกสกิลต้องมีป้ายช่วย เช่น "เข้าคอมโบกับ Frost" หรือ "นับเป็น Link" เพื่อรักษา pillar ข้อ 1

ชื่อสกิลประจำตัวและสกิลสายเป็นชื่อชั่วคราว ตัดสินใน #19
