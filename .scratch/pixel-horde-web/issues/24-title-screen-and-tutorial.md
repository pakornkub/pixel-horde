เพิ่มจาก #19 (2026-09-25): **ล็อกอินได้ทีละที่** หลายแท็บในเบราว์เซอร์เดียวกัน ใช้ Web Locks/BroadcastChannel แท็บที่เปิดทีหลังขึ้นว่า "เกมเปิดอยู่ในอีกแท็บ" พร้อมปุ่ม "ใช้แท็บนี้แทน" (แท็บเก่าหยุดทันที) ข้ามเครื่อง เครื่องล่าสุดชนะ เครื่องเก่าขึ้นข้อความ "บัญชีนี้ถูกเปิดที่อื่น" เมื่อคุยกับ server ครั้งถัดไป (กลไกฝั่ง server ดู #13)

## Answer

ตัดสินใจ 2026-09-25 (ผู้ใช้เห็นชอบทุกข้อ)

**หน้าแรก**
1. **องค์ประกอบ**: ปุ่ม "เล่น" ใหญ่สุดกลางจอ มีฮีโร่ที่เลือกยืนขยับอยู่เหนือปุ่ม · "เล่นต่อจาก Chapter N" เมื่อมีเซฟค้าง (#22) · เมนูรอง: ฮีโร่ + อาวุธ, Co-op, ด่านประจำวัน, อันดับ, ร้าน, **คลังสะสม** (อาวุธ, ฉายา, achievement), ตั้งค่า · มุมขวาบน: ชื่อ + "ผูก Google" · แถบประกาศจาก Admin คอม: โลโก้/ฮีโร่กลาง, เมนูรองด้านล่าง, ประกาศล่างสุด · มือถือ: เรียงแนวตั้ง, ปุ่มหลักอยู่ในระยะนิ้วโป้ง, ประกาศบนสุด
2. **ภาพพื้นหลังจาก Gemini** (ข้อยกเว้นจากกฎกราฟิก ในเกมยังวาดเอง): หัวใจคริสตัลลอยเหนือดินแดนของ Lumora ในสไตล์พิกเซลอาร์ตโทนสีเดียวกับเกม ทำ **2 ภาพ**: แนวนอน 16:9 (คอม) และแนวตั้ง 9:16 (มือถือ) ความมีชีวิตทำด้วยโค้ดทับบนภาพ (คริสตัลเรืองแสงเป็นจังหวะ, ประกายลอย, ฮีโร่ขยับ) ไฟล์ WebP ภาพละไม่เกิน ~300 KB แสดงสีพื้นระหว่างโหลด ภาพมีลายน้ำ SynthID มองไม่เห็นติดมา ใช้ได้ตามเงื่อนไขของ Google ตอนลงมือทำ Claude ใช้ skill สร้างภาพด้วย Gemini ทำหลายแบบให้ผู้ใช้เลือก
3. **ล็อกอินครั้งแรก**: ถามชื่อเล่นอย่างเดียว ข้ามได้ (ตั้งชื่อ "Hero#1234" ให้) · ชวนผูก Google 2 ครั้ง: หลังจบรอบที่ 3 และหลังชนะ Umbra ครั้งแรก · กรองคำหยาบพื้นฐานไทย/อังกฤษ + admin ซ่อนชื่อได้ · ข้อความล็อกอินซ้อน: "เกมเปิดอยู่ในอีกแท็บ" (ปุ่ม "ใช้แท็บนี้แทน") / "บัญชีนี้ถูกเปิดที่อื่น"

**ด่านสอนเล่น (Greenvale รอบแรกของบัญชี)**
4. **ลำดับ**: เดิน → สกิลยิงเอง "แค่เดินหลบ" → เก็บคริสตัล (ลูกศรชี้ก้อนแรก) → เลเวลอัปครั้งแรก → ท่าไม้ตายเมื่อเกจเต็มครั้งแรก → ราชาโผล่ "ล้มราชาถึงจะผ่านด่าน · เครื่องหมายแดง = หลบ" → หน้าจบด่าน (ช่องเก็บ + เลือกเส้นทาง) **สอนตอนเจอครั้งแรกภายหลัง**: คอมโบแรก, ได้ช่องเก็บเพิ่ม (Ch2), Blood Moon แรก, มังกรแรก, หน้าตื่นพลังแรก, ราชาหนีครั้งแรก
5. **รูปแบบ**: ข้อความสั้นบนจอ ไม่หยุดเกม (ยกเว้นหน้าเลเวลอัปที่หยุดอยู่แล้ว) ไม่มีด่านสอนแยก แต่ละคำแนะนำขึ้นครั้งเดียวต่อบัญชี ปิดได้ใน Setting + ปุ่ม "ดูคำแนะนำอีกครั้ง" **รอบแรกสุดของบัญชี** Greenvale ง่ายลงเล็กน้อย (ความกดดันเริ่มต่ำ, ราชา HP ×0.8)
6. **co-op**: คำแนะนำขึ้นเฉพาะคนที่ยังไม่เคยเห็น ไม่หยุดเกมเพื่อน ไม่ใช้ Greenvale แบบง่าย
