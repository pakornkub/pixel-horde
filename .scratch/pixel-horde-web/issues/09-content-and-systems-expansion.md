# Grilling: รายการเนื้อหาและระบบที่จะเพิ่ม เรียงตามความสำคัญ

Type: grilling
Status: resolved
Blocked by: 07

## Question

จะต่อยอดเนื้อหาและระบบอะไรบ้าง และอะไรมาก่อน? (ระบบสกิลแยกไป #18, ตัวละคร #19, เศรษฐกิจในรอบ #20, บอส #21, เซฟแล้วเล่นต่อ #22) ขอบเขตที่เหลือ: Theme/มอนใหม่ และจำนวน Stage ที่จะเพิ่ม (ร่วมกับ #08), ระบบ meta ใหม่ (achievement, ภารกิจ, สมุดรวมมอน, สกินที่ปลดล็อกได้) และสิ่งที่ทำให้ "ดาเมจสะใจ สกิลอลังการ" มากขึ้น (juice) ทุกข้อต้องเช็กกับ design pillars และต้องได้เป็นรายการเรียงลำดับ พร้อมระบุว่าอะไรต้องมีในรุ่นแรก

เพิ่มจาก #18: มอนของแต่ละดินแดนต้องตรงกับลักษณะเด่นและธาตุที่ทนตามตารางใน #18

เพิ่มจาก #15: achievement ปลดล็อกฉายาได้ (ระบบเดียวกับฉายาจากอันดับ Season) ตัวอย่าง: ปราบมังกร 3 หัว → "Dragon Tamer", ชนะด้วยฮีโร่ครบ 4 ตัว → "Legend of Lumora", ติดคอมโบ Shatter 1,000 ครั้ง → "Ice Breaker"

## Answer

ตัดสินใจ 2026-09-25 (ผู้ใช้เห็นชอบทุกข้อ)

**มอนประจำดินแดน** (ตัวรุม · ตัวเด่นของดินแดน · ตัวถึก / ทนธาตุ):
- Greenvale: สไลม์ · ค้างคาว (เร็ว) · เห็ด / -
- Sunscar: สไลม์ทราย · แมงป่อง (ฝูงเร็ว) · มัมมี่ใส่เกราะ / -
- Deepdark: ค้างคาว · โครงกระดูกนักธนู (ยิงไกล) · ผี / ความมืด
- Frostpeak: สไลม์น้ำแข็ง · ค้างคาวน้ำแข็ง · มนุษย์หิมะใส่เกราะ / น้ำแข็ง
- Emberforge: ค้างคาวไฟ · ซาลาแมนเดอร์ (เร็ว) · ก้อนหินลาวาใส่เกราะ / ไฟ
- Mirefen: กบพิษ (กระโดด) · เห็ดสปอร์ (แตกตัว) · ปลิงยักษ์ (ดูดเลือด) / พิษ
- Skyreach: ภูตเมฆ · นกพายุ (ฝูงบินเร็ว) · กริฟฟอนน้อย (พุ่งชาร์จ) / สายฟ้า
- Tidehollow: แมงกะพรุน · ปลาฟันเลื่อย (พุ่งชาร์จ) · ปูเกราะหนา / น้ำแข็ง
- Gearspire: แมงมุมเหล็ก · ป้อมปืน (ยิงไกล อยู่กับที่) · ทหารกลไกใส่เกราะ / สายฟ้า
- Duskhold: หนังสือบิน (ยิงเกลียว) · ผีโคมไฟ (ยิงไกล) · ชุดเกราะผี (ตายแล้วแตกเป็นผี) / ความมืด
- Heart Crater: ร่างเงาของมอนทุกดินแดนปนกัน

มอนแก้ทางเดิม (หมูป่า, ตาเวท, สไลม์แตกตัว, ตัวใส่เกราะ) โผล่ได้ทุกดินแดนโดยเปลี่ยนสีให้เข้ากับดินแดน รูปทรงใหม่ ~18 ตัว ที่เหลือเปลี่ยนสี (#10)

**ระบบ meta**:
- **Achievement ~30 รายการในรุ่นแรก** 5 หมวด: เนื้อเรื่อง, ฮีโร่, คอมโบ, มังกร, ท้าทาย บางรายการให้ฉายา (ตัวอย่าง: ชนะโดยไม่มีราชาหนี → "Kingslayer", ชนะครบ 4 ฮีโร่ → "Legend of Lumora", Shatter 1,000 ครั้ง → "Ice Breaker", ปราบมังกร 3 หัว → "Dragon Tamer") รายการเต็มเขียนตอนลงมือทำ นับจากสรุปผลรอบที่ส่ง server (#13)
- **สมุดรวมมอน ในรุ่นแรกแบบเบา**: ฆ่าครั้งแรกปลดล็อกหน้า (ภาพ + เรื่องราว 1 บรรทัด + จำนวนที่ฆ่า) ราชา/มังกรมีหน้าพิเศษ อยู่ในเมนูคลังสะสม
- **ภารกิจรายวัน/รายสัปดาห์: ไว้หลังเปิดเกม** (ต้องจูนเศรษฐกิจใหม่ รอสถิติจริง)
- **สกินฮีโร่**: รุ่นแรกมีแค่ชุดสี (จากอันดับ Season + achievement บางตัว) สกินเปลี่ยนรูปทรงไว้ทีหลัง

**ความสะใจ (juice)**: คงของเดิม (ตัวเลขดาเมจ, กระพริบ, จอสั่น, หยุดภาพ, แฟลช, ป้ายมอนแก้ทาง) และ**เพิ่มในรุ่นแรก**: (1) ชื่อคอมโบเด้งใหญ่ + เสียงเฉพาะ (2) ป้ายราชาตอนโผล่ ชื่อ + ฉายา + บทพูด (3) ราชาตายภาพช้าครึ่งวินาที + ระเบิด + คริสตัลพุ่งเข้าตัว (4) ช่วง Evolution/ตื่นพลัง/รวมร่างมังกร ซูมเข้า 1.5 วิ + ชื่อร่างใหม่ (5) Kill Streak "×50 KO!" (6) เอฟเฟกต์สถานะบนมอน (7) ท่าตายตามครอบครัวมอน (8) ดูดของตอนจบด่าน (9) เสียงทุกสกิล/คอมโบด้วย ZzFX + เพลงประจำดินแดนด้วย ZzFXM **ไว้ทีหลัง**: กล้องซูมกระแทก, ฉากช้ายาวตอนจบ Umbra ทุกอย่างปิด/ลดได้ใน Setting และมีเพดาน particle ต่อเฟรม

**ชื่อ**: ตัวนับการฆ่าต่อเนื่องเดิมในเกม (ตัวแปร `combo`) เปลี่ยนชื่อเป็น **Kill Streak** ไม่ให้ชนกับ Combo (คอมโบธาตุ)
