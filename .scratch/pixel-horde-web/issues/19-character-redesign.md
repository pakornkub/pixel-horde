# Grilling: ออกแบบตัวละครใหม่ให้ต่างกันชัด

Type: grilling
Status: resolved
Blocked by: 07

## Question

ตัวละครทั้ง 4 ตัว (Mage, Knight ฟรี / Ranger 150G, Alchemist 300G) จะต่างกันยังไง ทั้งตัวตนในเรื่อง, รูปลักษณ์ (สไปรต์ตัวอักษร ดู #10), ค่าสถานะ, **สกิลประจำตัว**ที่ตัวอื่นไม่มี, สายสกิลที่ได้หลังตื่นพลัง และราคาปลดล็อก ร่างใน #18 เสนอไว้: Mage/Arcane Sigil → Archmage, Knight/Holy Shield → Paladin, Ranger/Hawk Companion → Stormhunter, Alchemist/Volatile Flask → Grand Alchemist (ตัวละครสายคอมโบ) จะมีตัวละครเพิ่มหรือไม่ด้วย

เพิ่มจาก #07: ฮีโร่มีชื่อและตัวตนแล้ว: Lyra (Mage), Bram (Knight), Kit (Ranger), Vex (Alchemist สายคอมโบ) ดูตารางใน #07

เพิ่มจาก #18: สายสกิลของแต่ละฮีโร่ตกลงแล้ว (ดู #18) ต้องออกแบบสกิลประจำตัว 4 ตัว (Evo กับพาสซีฟของตัวเอง) และสกิลสาย 12 ตัว (ไม่มี Evolution เลเวลสูงสุดและพลังสูงกว่าสกิลทั่วไป)

## Answer

ตัดสินใจ 2026-09-25 (ผู้ใช้เห็นชอบทุกข้อ) ชื่อสกิลแก้ได้ภายหลัง

**บทบาท**: Lyra = สายเวทคุมพื้นที่ ดาเมจสูง แต่บาง · Bram = สายโล่ประชิด ทนสุด กันกระสุนได้ เหมาะกับมือใหม่ · Kit = สายเร็วระยะไกล ล่าตัวใหญ่ · Vex = สายคอมโบ สุ่มธาตุ ต้องเข้าใจระบบ

**สกิลประจำตัว (Signature Skill) และ Evolution**:
- Lyra **Arcane Sigil**: ประทับวงเวทที่พื้นใต้ตัวเป็นระยะ มอนในวงโดนดาเมจต่อเนื่อง · + Might → **Grand Sigil** (วงใหญ่ขึ้น ประทับทีละ 2)
- Bram **Holy Shield**: โล่ 1–3 อันหมุนรอบตัว **กันกระสุนมอน** และกระแทกกระเด็น · + Vitality → **Aegis** (ดูดซับดาเมจ ฟื้น HP เมื่อกันได้)
- Kit **Hawk Companion**: เหยี่ยวจิกมอนตัวใหญ่สุด/ไกลสุด · + Swift Boots → **Twin Hawks** (2 ตัว โฉบแล้วทำให้มึนงง)
- Vex **Volatile Flask**: ขวดยาสุ่มธาตุ ไฟ/น้ำแข็ง/พิษ ทิ้งสถานะ · + Haste → **Smart Flask** (ขว้าง 2 ขวด เลือกธาตุที่ต่อคอมโบกับสถานะบนมอนได้)

**ร่างตื่นพลังและสกิลสาย** (ไม่มี Evolution แต่แรงกว่าสกิลทั่วไป ทุกคนมีสกิลเอาตัวรอด 1 ตัว):
- Lyra → **Archmage**: Mana Nova (คลื่นเวทเป็นจังหวะ) · **Time Warp** (มอนในวงกว้างช้าลงมาก) · Starfall (ดาวตก)
- Bram → **Paladin**: Sacred Blades (ดาบแสงยักษ์ฟันตามทิศเดิน) · Judgement Pillar (เสาแสงลง elite/บอส) · **Aegis Dome** (อมตะ 2 วิ ทุก 20 วิ)
- Kit → **Stormhunter**: Arrow Rain (ฝนธนู) · **Gale Step** (เดินแล้วทิ้งใบมีดลมตามทาง) · Thunder Hawk (เหยี่ยวสายฟ้ากระโดดหลายเป้า)
- Vex → **Grand Alchemist**: Cauldron (หม้อยาพ่นสถานะทุกธาตุ) · Transmute (มอนตายในวงมีโอกาสกลายเป็นคริสตัล EXP ก้อนใหญ่ **ไม่ใช่ Gold** กันปั๊มเงิน) · **Elixir Rain** (ฟื้น HP + เร่งคูลดาวน์)

**ค่าสถานะติดตัว** (ลดจากเดิมเล็กน้อยตามแนวลดพลังรวมใน #18): Lyra ดาเมจสกิล +10% · Bram HP +40, ช้าลง 5% · Kit เร็วขึ้น 12%, ดูดของไกล 30% · Vex คูลดาวน์ −8%, สถานะอยู่นานขึ้น 20%

**ราคาปลดล็อก**: Lyra/Bram ฟรี · Kit **500G** · Vex **1,000G** (เดิม 150/300 ถูกเกินเมื่อรอบละ ~1,200 Gold)

**หน้าตา** (ต้องแยกออกได้แม้ตัวเล็กบนมือถือ): Lyra ม่วง หมวกแหลม + คทา · Bram แดง-เหล็ก หมวกเกราะขนนก + โล่กลม · Kit เขียว-น้ำตาล ฮู้ด + ธนูสะพายหลัง · Vex ฟ้า-ส้ม แว่นนักทดลอง + ขวดยาห้อยเอว (ขนาด/เฟรมใน #10)

**ฮีโร่เพิ่ม**: รุ่นแรก 4 คน แล้วเพิ่มเป็นเนื้อหา Season ใหม่ภายหลัง (ฮีโร่ใหม่ = สกิลประจำตัว + สกิลสาย 3 + Link 3) โครงระบบต้องรองรับการเพิ่มฮีโร่
