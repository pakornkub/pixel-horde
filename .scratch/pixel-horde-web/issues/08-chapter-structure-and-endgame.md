## Question

Run หนึ่งมีกี่ Chapter และกี่ Stage ต่อ Chapter? บอสใหญ่ตัวสุดท้ายอยู่ Stage ไหน (backlog เดิมเสนอ Stage 8) และจบแล้วมีอะไรต่อ (Endless mode / New Game+ / ปลดล็อกระดับความยาก)?
