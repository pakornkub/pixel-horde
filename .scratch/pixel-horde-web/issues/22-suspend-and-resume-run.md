# Grilling: เซฟระหว่างรอบแล้วกลับมาเล่นต่อ

Type: grilling
Status: resolved
Blocked by: -

## Question

ผู้เล่นกด Esc แล้วเลือกเซฟ ออกจากเกม แล้วกลับมาเล่นต่อได้ (ตายแล้วยังเริ่มใหม่เหมือนเดิม) ข้อแนะนำเริ่มต้น: เซฟเป็นจุดเริ่มของ Stage ที่กำลังเล่น (ไม่เซฟกลางด่าน), ช่องเซฟเดียว, โหลดแล้วเซฟหาย (กันเล่นซ้ำเพื่อโกงผล), เฉพาะ solo, ไม่เปิดในด่านท้าทายประจำวัน ต้องตัดสินว่าเก็บในเครื่องหรือบน cloud, รอบที่เซฟไว้ต่อกับ Run token ของ leaderboard (#05) ยังไง และถ้า Balance Config เปลี่ยนระหว่างนั้นจะทำยังไง

**ตัดสินแล้วบางส่วน 2026-09-25**: เซฟแล้วเล่นต่อ ใช้ได้ในโหมดหลัก (solo) และ **Endless (solo)** · ใช้ไม่ได้ใน co-op และด่านท้าทายประจำวัน · ตายแล้วยังเริ่มใหม่เสมอ ที่เหลือ (เก็บในเครื่องหรือ cloud, การต่อกับ Run token, Balance Config เปลี่ยนระหว่างนั้น) ยังต้องตัดสิน

## Answer

ตัดสินใจ 2026-09-24/25 (ผู้ใช้เห็นชอบทุกข้อ)

1. **ใช้ได้ที่ไหน**: โหมดหลักและ Endless เฉพาะเล่นคนเดียว · ใช้ไม่ได้ใน co-op และด่านท้าทายประจำวัน · ตายแล้วเริ่มใหม่เสมอ
2. **จุดเซฟ = จุดเริ่มของด่านที่กำลังเล่น**: มีช่องเดียว โหลดแล้วเซฟหาย (ใช้ได้ครั้งเดียว) **เซฟอัตโนมัติทุกครั้งที่เริ่มด่าน** และกด Esc → "เซฟแล้วออก" ได้ เปิดเกมใหม่ (แม้เบราว์เซอร์ถูกปิดหรือค้าง) จะขึ้น "เล่นต่อจาก Chapter N?" ตอนออก หน้าจอบอกชัดว่า EXP และ Gold ที่ได้ในด่านที่ยังเล่นไม่จบจะหายไป
3. **เก็บบน server + สำเนาในเครื่อง**: state ของ sim ตอนเริ่มด่าน (~5–20 KB, ไม่มีมอนบนจอ) server เก็บรหัสตรวจสอบ (hash) ของเซฟล่าสุดของรอบ ถ้าโหลดเซฟที่ถูกก๊อปไว้ รหัสไม่ตรงแล้ว `submit_run` จะไม่รับ เล่นต่อข้ามเครื่องได้ ถ้าออฟไลน์ใช้สำเนาในเครื่องแล้วค่อยยืนยันเมื่อต่อเน็ต (ตารางเพิ่ม: `run_checkpoints` หรือคอลัมน์ใน `runs`: checkpoint blob, checkpoint_hash, chapter, config_version; `runs.status` เพิ่มค่า `suspended`)
4. **เวลาในกันโกง**: Run token ใช้ได้ตลอดช่วงพัก server จดเวลาพัก/กลับมาทุกครั้ง แล้วเช็กว่าเวลาที่เล่นจริงรวมทุกช่วงไม่น้อยกว่าเวลาขั้นต่ำ
5. **Balance Config**: ด่านที่กลับมาเล่นใช้เวอร์ชันที่บันทึกในเซฟ ส่วนด่านถัดไปใช้เวอร์ชันปัจจุบัน
6. **อายุเซฟ**: อยู่จนกว่าจะเริ่มรอบใหม่หรือครบ 30 วัน ถ้าจะเริ่มรอบใหม่ทั้งที่มีเซฟค้าง ต้องยืนยันก่อน ("เริ่มใหม่จะทิ้งรอบที่เซฟไว้ (Chapter 5, Lyra)")
7. **Season จบระหว่างพัก**: เล่นต่อจนจบได้ ได้ Gold และของตามปกติ แต่**ไม่ขึ้นตารางอันดับ** แจ้งผู้เล่นตอนกดเล่นต่อ
8. เข้ากับกติกาล็อกอินได้ทีละที่ (#13): เซฟบน server เป็นของบัญชี เครื่องที่ล็อกอินล่าสุดเป็นคนเล่นต่อ
