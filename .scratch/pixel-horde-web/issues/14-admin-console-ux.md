# Prototype: หน้าจอและการใช้งาน Admin Console

Type: prototype
Status: claimed
Blocked by: 13

## Question

Admin Console v1 ควรมีหน้าจออะไรบ้าง และใช้งานยังไง? ทำ prototype หยาบๆ ให้ผู้ใช้ลองกดดู ครอบคลุม: แก้ Balance Config (ตัวคูณ, ช่วงค่า, เทียบกับเวอร์ชันก่อน, publish, rollback, ปุ่มทดสอบสดในเครื่อง), feature flags และโหมดปิดปรับปรุง, ตั้งอีเวนต์ตามเวลาและด่านท้าทายประจำวัน, dashboard สถิติ, ดูแล leaderboard และ Season, แจกเหรียญ/รีเซ็ตบัญชี, ประกาศ และ audit log

เพิ่มจาก #15: หน้าจอ Leaderboard ใน Admin ต้องมีการตรวจอันดับต้นๆ ของ co-op ด้วยตาก่อนแจกรางวัลจบ Season และหน้าเปิด Season ใหม่ต้องแสดงรายชื่อผู้ได้รางวัลให้ยืนยัน
