# Grilling: รายละเอียด co-op บนช่องทางใหม่

Type: grilling
Status: resolved
Blocked by: 03, 12

## Question

co-op 2–4 คนแบบรหัสห้องจะทำงานยังไงบนช่องทางที่เลือกใน #12: สร้างห้องและเข้าห้องยังไง, ชื่อเล่นแสดงยังไง, จะคงโปรโตคอลเดิม (Host เป็นคนคำนวณ, Guest ยิงสกิลเองแล้วส่งดาเมจกลับ) ไว้ หรือต้องปรับอะไร, Host หลุดแล้วเกิดอะไรขึ้น, Balance Config ของใครใช้ตอนเล่นด้วยกัน, สวิตช์ปิด co-op ใน admin มีผลยังไง และ Meta Progression/Gold ของแต่ละคนได้มายังไง

เพิ่มจาก #18: co-op รุ่นแรก คอมโบเกิดเฉพาะสกิลของผู้เล่นคนเดียวกัน (สถานะมอนไม่ถูกส่งข้ามเครื่อง) คอมโบข้ามผู้เล่นเป็นงานภายหลัง

## Answer

ตัดสินใจ 2026-09-25 (ผู้ใช้เห็นชอบทุกข้อ) รวมกติกา co-op ทั้งหมดไว้ที่นี่

**ที่ตัดสินไว้แล้วจาก ticket อื่น**: 2–4 คน, รหัสห้อง, ห้อง = Cloudflare Durable Object ผ่าน PartyServer (#03/#12/#11), โฮสต์คำนวณโลก เพื่อนคำนวณสกิลตัวเองแล้วส่งดาเมจกลับ (โปรโตคอลเดิม), คอมโบและมังกรเกิดเฉพาะของตัวเอง (#18/#21), คะแนนทีมละแถว ติดป้าย "ยังไม่ยืนยัน" (#15), ใบเกิดใช้ลุกทันที (#20), เซฟกลางรอบไม่ได้ (#22), สวิตช์ co-op ใน Admin และข้อความ "co-op เต็มวันนี้" เมื่อโควตาหมด (#12), ล็อกอินได้ทีละที่ (#13)

1. **สร้าง/เข้าห้อง**: รหัส 5 ตัว (ตัดตัวที่สับสน O/0, I/1) + ลิงก์ชวน (`?room=CODE`) → ห้องรอ เลือกฮีโร่/อาวุธ, กด "พร้อม", โฮสต์กดเริ่ม **เข้าได้เฉพาะในห้องรอ** คนที่หลุดกลับเข้าได้ แต่คนใหม่เข้ากลางรอบไม่ได้ (ไว้เป็นงานภายหลัง)
2. **การตัดสินใจ**: เลือกดินแดนโดยโหวต 15 วิ เสมอให้โฮสต์ตัดสิน · เลเวลอัปและหีบทั้งห้องรอ (phase `wait` เดิม) · หน้าจบด่านแต่ละคนจัดการของตัวเองพร้อมกัน (ช่องเก็บ, ตื่นพลัง, สลับมังกร/อาวุธ) รอทุกคน "พร้อม" หรือครบ 30 วิ
3. **ความยาก**: มอนเกิดเพิ่ม 60% ต่อเพื่อน 1 คน (เดิม) + HP ของราชา/มังกร/Umbra ×(1 + 0.6 × จำนวนเพื่อน)
4. **ของที่ได้**: EXP รวมทั้งทีม ทุกคนได้เท่ากัน · Gold ทุกคนได้ตามจำนวนมอนที่ทีมฆ่า คิด Greed ของตัวเอง · รางวัลราชาทุกคนได้ครบชุดของตัวเอง (Gold + แต้มสกิล + หีบ + ลุ้นอาวุธ 5% แยก) · ปราบมังกรแล้วทุกคนได้มังกรคู่ใจของตัวเอง · ของถาวรเข้าบัญชีแต่ละคน
5. **ล้มและลุก**: ล้มแล้วรอผ่านด่าน, หรือซื้อใบเกิดลุกทันที, หรือ**เพื่อนยืนข้างครบ 3 วิ ลุกพร้อม HP 30%** (ช่วยได้คนละ 1 ครั้งต่อด่าน) ทุกคนล้ม = จบรอบทั้งทีม
6. **โฮสต์หลุด**: กลับมาภายใน 10 วิ เล่นต่อได้เลย · เกิน 10 วิ ห้องตั้งเพื่อนที่เข้าห้องก่อนสุดเป็นโฮสต์ใหม่ แล้ว**เริ่มด่านปัจจุบันใหม่จากเซฟต้นด่าน** (โฮสต์ส่งเซฟต้นด่านแบบเดียวกับ #22 เก็บไว้ในห้องทุกต้นด่าน) ของที่ได้ในด่านนั้นหาย แต่ทีมไม่ต้องเริ่มรอบใหม่ · เพื่อนหลุดเกินเวลา: คนนั้นจบรอบของตัวเอง (Gold เข้ากระเป๋า) ทีมเล่นต่อ
7. **Balance Config**: ทั้งห้องใช้เวอร์ชันของโฮสต์ (โฮสต์ส่งเลขเวอร์ชัน เพื่อนโหลดเวอร์ชันนั้นมาคำนวณสกิลให้ตรงกัน) · เช็กสวิตช์ co-op ตอนสร้างและเข้าห้อง ถ้า admin ปิดระหว่างเล่น รอบปัจจุบันเล่นจนจบได้ แต่สร้างห้องใหม่ไม่ได้
8. **Endless**: หลังชนะ Umbra ทุกคนโหวตว่าจะเล่นต่อไหม คนที่ไม่อยากต่อออกพร้อมรับของได้ ที่เหลือเล่นต่อ คะแนนเข้าตาราง Endless แบบ co-op
