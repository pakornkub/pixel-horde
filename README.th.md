### มีอะไรให้เล่น

- **ฮีโร่ 4 คน** — Lyra (เวทคุมพื้นที่), Bram (อัศวินโล่), Kit (นักล่าความเร็วสูง), Vex (นักเล่นแร่แปรธาตุสายคอมโบ) มีสกิลประจำตัว และ **ตื่นพลัง** เป็นร่างใหม่พร้อมสกิลตื่นพลัง 3 ตัว (ค่าสมดุลปัจจุบัน: Link ยังอยู่ และได้ช่องสกิลโจมตีช่องที่ 5)
- **สกิล 28 ตัว พาสซีฟ 6 แบบ วิวัฒน์ 16 แบบ** — อัปสกิลจนเต็ม + มีพาสซีฟคู่ = วิวัฒน์ มีช่องสำรอง (Bench) เก็บสกิลและพาสซีฟไว้ใช้ทีหลัง
- **คอมโบธาตุ 7 แบบ** — แช่แข็งแล้วทุบ (*Shatter*), ช็อตแล้วเผา (*Overload*), ดูดรวมแล้วกวาด (*Grinder*)…
- **ราชา 10 องค์ + Umbra** — ทุกท่ามีพื้นที่เตือนสีแดง มีท่าไม้ตายเมื่อเลือดต่ำ และพูดเยอะมาก
- **ด่านพิเศษ** — คืน Blood Moon, มังกรผู้พิทักษ์ 3 ตัวให้ปราบมาเป็นพวก (และรวมร่าง), Shadow Rival, ด่านราชา 2 องค์
- **อาวุธ 11 ชิ้น** แต่ละชิ้นมีท่าไม้ตายของตัวเอง (Judgement, Solar Flare, Thunderstorm…) ร้านอัปเกรดถาวร ความสำเร็จ ฉายา และกระดานอันดับตาม Season
- **ระดับความยาก 6 แบบ** สำหรับเล่นเดี่ยว ตั้งแต่ เพลินๆ ถึง เทพไว (นับอันดับเฉพาะ สมดุล แบบอื่นยังได้ Gold) ปรับระยะกล้องได้ และมีปุ่ม **ส่งความเห็น** ในเกม
- **เล่นกับเพื่อนได้ 4 คน** ผ่านลิงก์ชวนลิงก์เดียว และเล่นคนเดียว **ออฟไลน์** ได้
- **ไทย / English** ทั้งเกมและเว็บไซต์ ทุกการเปลี่ยนแปลงอ่านได้ที่หน้า [อัปเดต](https://pixel-horde.pages.dev/updates.html?lang=th) บนเว็บ และหน้าแรกของเกมจะบอกอัปเดตล่าสุด

## สำหรับนักพัฒนา

รายละเอียดโครงสร้างโค้ดและคำสั่งอยู่ใน [README ภาษาอังกฤษ](README.md#for-developers) สรุปสั้น ๆ:

```bash
npm install
npm run dev          # เกม  → http://localhost:5173
npm run dev:site     # เว็บ  → http://localhost:5180
npm run check        # lint + typecheck + test + build
npm run build:pages  # เว็บที่ / และเกมที่ /play/ → dist/pages
npm run test:browser # Playwright: เกมที่ build แล้ว + Admin บน Chromium / Firefox / WebKit
npm run playtest -- heroes 16   # บอททดสอบบาลานซ์ ดู scripts/playtest/README.md
```

- ธงใน URL ของเกม: `?offline` (ไม่ต่อ backend ใช้ Balance Config ที่แคชไว้ล่าสุด ถ้าไม่มีใช้ค่าเริ่มต้นในเกม) และ
  `?debug=god|bloodmoon|dragon|frostdragon|stormdragon|rival|realm:<id>` (คั่นด้วยจุลภาค) เพื่อบังคับให้เกิดเหตุการณ์
  กด **I** ระหว่างเล่นเพื่อดูมิเตอร์บาลานซ์ (DPS, TTK, ตัวคูณ, Director, จำนวนมอน)
- การปรับบาลานซ์ไม่แก้ค่าเริ่มต้นในโค้ด: รอบจูนอยู่ใน `packages/config/src/balance-pass.ts` แล้วเผยแพร่เป็น
  Balance Config เวอร์ชันใหม่จาก Admin → Balance พร้อมรายงานและบันทึกอัปเดต
- ภาพหน้าจอบนเว็บและใน README เป็นภาพจริงจากเกม: `npm run shots` (ดู [docs/deploy.md](docs/deploy.md))

เว็บไซต์ (`apps/site`) ดึงข้อมูลสกิล ตัวเลข คอมโบ ดินแดน สไปรต์ และคำแปลไทย/อังกฤษจากโค้ดเกมโดยตรง
แก้เกมแล้ว build ใหม่ เว็บก็อัปเดตตาม
